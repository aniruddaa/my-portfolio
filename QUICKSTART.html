📧 Contact Form Setup

Currently, messages are stored in your browser's localStorage. To send emails:

  1. Create a backend service (Node.js, Python, PHP, etc.)
  2. Set up an email service (Gmail, SendGrid, Mailgun, etc.)
  3. Update the form submission in js/script.js
⚠️ Important: For production, implement proper backend validation and security measures.

🌐 Deployment Options

GitHub Pages (Free)

  1. Create a GitHub account
  2. Create a new repository named portfolio
  3. Upload your files
  4. Go to Settings → Pages and enable GitHub Pages
  5. Your site will be live at https://yourusername.github.io/portfolio

Netlify (Free)

  1. Go to netlify.com
  2. Click "Deploy" and drag-drop your portfolio folder
  3. Your site goes live instantly!
  4. Get a custom domain or use their subdomain

Traditional Web Hosting

Upload all files to your hosting provider via FTP

🐛 Troubleshooting

Website not loading?

  • Make sure all files are in the correct folders
  • Check file paths in index.html
  • Try a different browser
  • Clear browser cache (Ctrl+Shift+Delete)

Admin panel issues?

  • Check browser localStorage is enabled
  • Clear localStorage and try again
  • Check browser console for errors (F12)
  • Ensure JavaScript is enabled

Animations not showing?

  • Verify CDN links are working
  • Check if CSS file is properly linked
  • Try disabling browser extensions
